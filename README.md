# シルエット格闘

影（シルエット）の剣士と拳法家が夕焼けの荒野で戦う、ブラウザで遊ぶ1人用の2D格闘ゲームです。

## 遊び方

`index.html` をブラウザで開くだけで動きます（インストール不要）。

| 操作 | キー |
| --- | --- |
| 左右に移動 | A / D |
| しゃがみ | S |
| ジャンプ | スペース（方向キーと一緒で斜めジャンプ） |
| 立ちガード | 相手と反対の方向キー |
| しゃがみガード | S＋相手と反対の方向キー |
| ステップ（カゲツ）／ダッシュ（リン） | 前を素早く2回（リンは押している間走る） |
| バックステップ | 後ろを素早く2回 |
| 弱攻撃 / 強攻撃 | U / I |
| しゃがみ攻撃 | S＋U / S＋I（下段：しゃがみガードでしか防げない） |
| 空中攻撃 | ジャンプ中に U / I（立ちガードでしか防げない。1回のジャンプで1回） |
| 必殺技 | O（カゲツ：飛刃＝飛び道具、リン：突進拳） |
| 対空の必殺技 | S＋O（カゲツ：昇り斬り、リン：跳び蹴り上げ） |
| 投げ | 相手の近くで U＋I 同時押し（ガードできない） |
| 投げ抜け | 投げられてから8F以内に U＋I |
| キャラを切り替え（仮） | 1：カゲツ / 2：リン（試合を最初から） |
| 練習相手の動きを切り替え（仮） | 3：何もしない／立ちガード／しゃがみガード／立ちガード＋投げ抜け／攻撃をくり返す |
| 当たり判定を表示 | H（青＝やられる範囲、赤＝当たる範囲、緑＝投げの掴める範囲、黄色の点線＝影縫い範囲） |
| 試合のあともう一度 | Enter |

- 必殺技キャンセル：地上の U・I（しゃがみも）が当たったかガードされたら、その技の途中で O / S＋O を押すと必殺技が出る。空振りからは出ない。
- 通常技の連続技：当たった（ガードされた）U から I につなげられる。リンは U → U → I もできる。
- コンボ補正：連続技の1発目は100%、2発目90%、3発目80%…と10%ずつ下がり、10発目からはずっと10%。2発以上つながると画面にヒット数と合計ダメージが出る。
- 削り：必殺技はガードされても、ダメージの1割だけ体力が減る。
- 投げ：U と I は2Fずれて押しても同時押しになる。のけぞり・ガード硬直・ダウン中の相手や空中の相手は投げられない。空振りすると同じくらいの発生の技より長く動けない。投げ抜けすると両方離れて五分になる。
- 技やのけぞりで動けない間に押した攻撃・ジャンプ・ステップ類（方向キー2回）は、動けるようになった最初のフレームで出ます（先行入力。何度か押したら最後に押したものが出ます）。
- ガードすると守った側はその場に踏みとどまり、攻めた側が下がります（ガードバック）。
- 影縫い：相手が技を出してから当たる時間が終わるまで、その技の当たる範囲より少し大きい範囲（Hキーで黄色の点線）に体が入っていると、後ろを押しても下がらずその場で立ちガードの構えになります。押した瞬間に届く距離の技は、下がって避けられません。

今は制作順4「2キャラの技をすべて入れる」の段階です。弱・強・しゃがみ・空中の攻撃、必殺技、キャンセル、連続技、投げと投げ抜けがあります。体力、60秒の制限時間、2ラウンド先取があります。右の相手は仮の練習相手で、CPUは制作順5で作ります。

## しくみ

- `src/core/characters.js` … キャラごとの数値の表（歩きの速さ、ジャンプの高さ、体の大きさ、体力、技の発生・硬直・硬直差・ダメージ・当たる範囲）と、ラウンドの時間などの共通ルール。調整はここだけ書き換えればよい。
- `src/core/dummy.js` … 仮の練習相手。プレイヤーと同じキー入力を作って右の相手を動かす。
- `src/core/` … ゲームの計算部分。画面やキーボードにはさわらず、「状態」と「入力」から次の1フレームを計算するだけ。計算は1秒60回で固定。
- `src/browser/` … ブラウザで動かす部分（キー入力、画面の描画、60回/秒のループ）。
- `tools/headless-check.js` … 画面なしで計算部分だけを動かし、同じ種（シード）なら同じ結果になるか、技の発生・硬直差・ダメージが表どおりか、ガード・下段・連続技・コンボ補正・投げ・投げ抜け・ラウンド・制限時間が決まりどおりか、どれくらい速いかを確かめる。`npm test` で実行。
