# KAGE

影（シルエット）の剣士と拳法家と悪役の術師と投げの大男が夕焼けの荒野で戦う、ブラウザで遊ぶ1人用の2D格闘ゲームです。

## 遊び方

`index.html` をブラウザで開くだけで動きます（インストール不要）。

1. タイトル画面で Enter（右下にバージョンが出ます。今は ver 0.6.2）。
2. モードをえらぶ（3つ）：
   - **対戦**：「対戦のしかた」で **あなた VS CPU** か **CPU VS CPU（観戦）** を選び、キャラとCPUの強さを決めて戦う。
   - **トレーニング**：時間無制限で、KOにならず、連続技が途切れると体力が満タンに戻る練習。「相手の動き」で練習相手（何もしない・ガード・攻撃をくり返す など）かCPUを選ぶ。試合中は最後に出した技の発生・持続・硬直・有利フレームが左に出る。H で当たり判定、G でゲージをずっと満タン、3 で相手の動きを変える、4 でCPUにする。
   - **資料**：基本の動き・攻撃・つなぎとゲージ・キャラごとの技とフレーム表・便利なキー・キーの変更（キーコンフィグ）のページを ←→ でめくる。試合中も Esc →「資料を見る」で開ける。
3. キャラ選択画面には4人のカードが並び、だれを選んでいるかが「あなた／相手」（観戦は「左／右」）の札でわかります。同じキャラ同士も選べます（右の差し色が変わります）。
4. 試合が終わると「もう一度・キャラ選択にもどる・タイトルにもどる」をえらべます。

**学習AI**：CPUの強さで「学習AI」を選ぶと、そのCPUは出ている試合（対戦・観戦・トレーニング）すべてから学び続けます（学んだ分はこのブラウザに保存）。はじめはゲームに入っている学習データから始まります。「自動対戦と記録」「学習AIをきたえる」の画面はメニューから外しました（`node tools/auto-battle.js`・`node tools/train.js` はそのまま使えます）。

メニューは矢印キーか WASD でえらび、Enter（または U・スペース）で決定、Esc（または I）でもどります（キーコンフィグで操作キーを変えたときは、矢印キー・Enter・Esc に加えて、変えたあとの移動・しゃがみ・ジャンプ・弱攻撃・強攻撃のキーで同じように動かせます）。キャラ選択では Enter を押すと次の項目へ進むので、決めたら Enter を続けて押すだけで始まります。前にえらんだキャラと強さはモードごとに覚えています。

### キーコンフィグ（操作キーを変える）

「資料」の最後のページ「キーの変更」で Enter を押すと、左右の移動・しゃがみ・ジャンプ・弱攻撃・強攻撃・必殺技のキーを好きなキーに変えられます。

- 変えたい操作を ↑↓ でえらんで Enter を押し、使いたいキーを押すと決まります（Esc で取り消し）。決めると次の操作に進むので、上から順に決めていけます。
- ほかの操作で使っているキーを押すと、2つのキーが入れ替わります。
- 「初期値にもどす」で A / D / S / スペース / U / I / O にもどります。
- 変えたキーはこのブラウザに保存され、次に開いたときもそのまま使えます。「資料」の説明も、変えたキーで表示されます。
- Esc（一時停止とキー待ちの取り消しに使う）・Tab・F1〜F12 などは割り当てられません。H・3・4 を試合の操作に割り当てたときは、その確認用の機能（当たり判定の表示・練習相手）は使えなくなります。
- 下の表は初期値のキーで書いています。投げ（弱＋強の同時押し）、ため攻撃（必殺技のキーを押してためて離す）、先行入力などは、変えたキーでもそのまま使えます。

- 必殺技キャンセル：地上の U・I・S＋U が当たったかガードされたら、その技の途中で O / S＋O を押すと必殺技が出る。S＋I（足払い）と空振りからは出ない。
- 同時に当たったとき：弱と強なら強だけが当たる。同じ強さ（必殺技は強と同じ）なら相打ち。投げと攻撃なら攻撃が勝つ。
- 技を出すと、やられる範囲が前に伸びる。当たる時間は当たる範囲と同じくらいまで、発生前と硬直中はその半分まで。投げと飛刃も同じ。対空技（S＋O）は上側に伸びる分が小さい。
- 通常技の連続技：当たった（ガードされた）U から I につなげられる。リンは U → U → I もできる。
- コンボ補正：連続技の1発目は100%、2発目90%、3発目80%…と10%ずつ下がり、10発目からはずっと10%。2発以上つながると画面にヒット数と合計ダメージが出る。
- 削り：必殺技はガードされても、ダメージの1割だけ体力が減る。
- 投げ：U と I は2Fずれて押しても同時押しになる。のけぞり・ガード硬直・ダウン中の相手や空中の相手は投げられない。空振りすると同じくらいの発生の技より長く動けない。投げきったあとも30F動けない（相手が起き上がるまでの有利は約+20F）。投げ抜けすると両方離れて五分になる。
- 空中攻撃の有利は当てた高さで変わる。下りの低い所（着地の12F前より下）で当てると技の表どおりで、それより高い所で当てるほど有利が減る。ジャンプしてすぐ出して当てても連続技にはならない。
- 技やのけぞりで動けない間に押した攻撃・ジャンプ・ステップ類（方向キー2回）は、動けるようになった最初のフレームで出ます（先行入力。何度か押したら最後に押したものが出ます）。攻撃ボタンのあとに左右の移動キーを押すと、その攻撃は取り消されます。
- 向き直り：地上で自由に動けるときのほか、ステップやワープの止まり際・着地硬直・のけぞりやガード硬直の間も相手の方を向き直ります（裏に回られても、動けるようになった瞬間から正しい向き）。技の最中・空中・ダウン中は向きを変えません。
- ガードすると守った側はその場に踏みとどまり、攻めた側が下がります（ガードバック）。
- 影縫い：相手が技を出してから当たる時間が終わるまで、その技の当たる範囲より少し大きい範囲（Hキーで黄色の点線）に体が入っていると、後ろを押しても下がらずその場で立ちガードの構えになります。押した瞬間に届く距離の技は、下がって避けられません。

今は4人目のキャラ「ゴウ」を足した段階です（下の「ゴウ（4人目のキャラ）」）。

### ゲージとゲージ技

体力バーの下にゲージがあります。満タンになると光って「ゲージ技 I＋O」と出るので、**I＋O の同時押し**でゲージ技が出ます（ゲージを全部使います）。

- **溜まり方**：相手の体力を1割減らすと5、自分が1割減らされると4、技をガードさせると少し（技のダメージが相手の体力の1割なら1.5）。ガードした側も溜まる（技のダメージが自分の体力の1割なら2、飛び道具や冥府球は食らったときと同じ4）。100で満タン。体力の割合で数えるので、体力の少ないゲンマも同じだけ溜まります。ゲージ技そのものでは溜まりません。
- **次のラウンドに持ち越します**。
- I と O は2Fずれて押しても同時押しになります（先に出かけた強攻撃や必殺技がゲージ技に変わる）。**どんな技の途中でも（空振りや硬直中でも）キャンセルして出せます**。リンの練気は空中でも出せます。満タンでないときの I＋O は今までどおりです。
- **消極的だとゲージが減る**：前に出ず（その場にいる・下がる・しゃがむ・バックステップ）、飛び道具しか撃たない時間が5秒続くと、そこから1秒ごとにゲージが3減ります（「消極的！ゲージ減少」と出る）。前に歩く・走る・前へステップやワープ・前ジャンプ、飛び道具でない攻撃（投げ・ゲージ技も）をすると数え直しです。攻撃を受けている・ガードしている・倒れている間は数えません。
- 出した瞬間に画面が暗くなって40F止まり（暗転）、技の名前が出ます。止まっている間に押したボタンは、動き出した最初のフレームで出ます（先行入力）。

| キャラ | ゲージ技 | どんな技か |
| --- | --- | --- |
| カゲツ | 月影斬 | 約240pxを一瞬で駆け抜けて斬る（250ダメージ、ダウン）。出だし10Fは無敵で、相手の攻撃に合わせて切り返せる。**暗転する前からガード（後ろ）を押していないとガードできない**（暗転してから押しても間に合わない）。ガードされても −2 だけ。 |
| リン | 練気 | 構えはなく、暗転が終わったらすぐ動ける。**6秒（360F）の間、すべての攻撃が当たるかガードされたら別の攻撃でキャンセルできる**（ふだんはできない足払いや必殺技、空中攻撃からも）。ゲージの下に残り時間が出る。 |
| ゲンマ | 冥府球 | 目の前に大きな闇の球を出し、ゆっくり（2.5px/F）進ませる。当たると8回まで連続で当たり、最後の1発でダウン（合計約210）。空中の相手に当たっても、球の中に浮かせたまま運んで最後まで当たり続ける。**ガードされても消えずに、相手を押し出しながら連続でガードさせる**（1発ごとに削り4）。相手の飛び道具は消して進む。ジャンプで飛び越えられる。 |
| ゴウ | 大地落とし | 約250px先まで突進して掴み、相手を担いで高く跳んで叩きつける（320ダメージ、ダウン）。**ガードも投げ抜けもできない**。出だし（16F）は飛び道具をすり抜ける。**暗転したときに地上にいた相手は、暗転を見てから跳んでも、バックステップやワープをしても掴む**（カゲツの月影斬と同じく、暗転のあとでは対応できない）。暗転する前から跳んでいた相手や、のけぞり・ガード中の相手は掴めず、空振りすると70F動けない。 |

CPU（よわい・ふつう・つよい・学習AI）も、ゲージが満タンになると使います（使う確率は よわい20%・ふつう50%・つよい80%）。カゲツの月影斬とゴウの大地落としは、攻められているときの切り返しと、相手が牽制などの技を出したのを見て（届く距離なら）撃ちます（技1つごとに上の確率）。リンは近づいて攻めている最中に練気を使い、練気の間は I・S＋U・S＋I と突進拳を交互にキャンセルして、ガードされても攻め続けます。ゲンマは離れた所から冥府球を撃ち、ガードさせたら球の後ろについて行って、上りの空中攻撃と下段で崩します。学習AIもこの決まりで使います（学習した表にはゲージ技は入っていません）。


### ゴウ（4人目のキャラ）

体力1300（一番多い）で体も一番大きい投げの大男。歩きは遅く（前1.7・後ろ1.4px/F）、ジャンプも低い（約127px、着地硬直5F）。近づくまでが勝負で、触れば投げで一気に大ダメージを取ります。

| 操作 | 技 | 中身 |
| --- | --- | --- |
| U | 張り手 | 発生7F・60ダメージ。**弱攻撃なのにリーチが長い**（体の中心から125px、強攻撃より長い）。そのかわり**腕のやられる範囲も同じだけ前に出る**ので、強攻撃を合わされると負ける（弱と強が同じフレームに当たったら強だけが当たる決まりも同じ）。ヒット+2・ガード0 |
| I | 大張り手 | 発生18F（遅い）・130ダメージ。**踏ん張り**：3〜21F目に受けた攻撃は1発だけ受け止めて、止まらずに殴る（ダメージは受ける。2発目は受け止められない。ゲージ技は受け止められない。投げには負ける）。受け止めると「踏ん張り！」と出て体が光る。ヒット+3・ガード−6 |
| S＋U | すね蹴り | 下段・発生8F・50ダメージ |
| S＋I | 四股踏み | 下段・発生16F・120ダメージ・ダウン。当たった・ガードされた 張り手（U）と すね蹴り（S＋U）から、S を押したまま I でキャンセルして出せる |
| ジャンプ中 U / I | 肘落とし／ボディプレス | ボディプレスは体ごと落ちてくるので下向きに広い |
| U＋I | ベアハッグ（投げ） | 160ダメージ（普通の投げより大きい）。投げ抜けできる |
| O | 岩落とし（コマンド投げ） | 発生8F・掴める範囲は体の中心から85px（普通の投げは55〜65px）・200ダメージ。**投げ抜けできない**。相手を頭の上まで持ち上げてから前へ叩きつける。普通の投げと同じく、のけぞり・ガード中や空中の相手は掴めず、打撃には負ける。空振りすると40F動けない |
| S＋O | つかみ上げ（対空投げ） | 頭の上の**空中の相手だけ**を掴んで叩きつける（150ダメージ、投げ抜けできない）。出だし12Fは空中の相手の攻撃が当たらないので、跳び込みの空中攻撃に勝つ。地上の相手は掴めない（空振りは30F動けない） |
| 前を2回 | 踏み込み | ゆっくり約50px進む。**踏み込んでいる間（14F）は飛び道具をすり抜ける** |

- 投げ抜けできない投げ（岩落とし・つかみ上げ・大地落とし）で掴んでいる間は、ゴウにも攻撃が当たりません。
- CPUのゴウは、踏み込みとガードで近づき、近ければ岩落としと投げ、張り手で止めます。相手が跳んできたらつかみ上げ。
- ほかのキャラのCPUは、ゴウの岩落とし・大地落としを読んで逃げます（岩落としは弱攻撃で止める。大地落としは暗転のあとでは避けられないので読まない）。読む確率は投げ抜けする確率と同じ（よわい0%・ふつう30%・つよい60%）。
- 「つよい」同士の勝率（自動対戦200試合）：ゴウ対カゲツ 5%、ゴウ対リン 91%、ゴウ対ゲンマ 99%。CPU同士はもともと差が大きく（カゲツ対リン 91%、カゲツ対ゲンマ 100%）、その中で カゲツ＞ゴウ＞リン＞ゲンマ の順です。
- CPUのゴウは、相手をダウンさせたら起き攻めをします：起き上がりに岩落としを重ねるか、様子を見て、跳んだらつかみ上げ、バックステップしたら張り手で止まり際を叩き、何もしなければ岩落とし。
- 学習AI同士では、リンはゴウに大きく不利です（4%。ゴウの岩落としに掴まれ続ける）。今はこの組み合わせのまま残しています。

### ゲンマ（3人目のキャラ）

体力500（カゲツの半分）の悪役。触られる前に削り切るキャラです。

- **ワープ**：前を素早く2回で消えて170px先に、後ろを2回で170px後ろに現れる（現れたあと前18F・後ろ20F動けない）。消えている12Fは攻撃も投げも当たらない。相手のすぐ前からワープすると、すり抜けて裏に出る（相手のガードの向きが変わる）。現れたあとは動けない時間があり、後ろワープのあとに攻撃や投げを受けると隙狩り（バックステップと同じ）。
- **浮遊**：ジャンプの頂上を過ぎてからスペースを押し続けると、最大40F浮いて止まる。浮いている間は左右のキーで自由に動け（2.5px/F）、押さなければその場に止まる。浮いている間は、やられる範囲の下側が50px小さくなる（衣のすそには当たらない）。浮いている間も空中攻撃や空中の異空間弾を出せる。
- **異空間弾**：自分の220px先に開いた門から弾が出て、相手の高さへ曲がっていく（ホーミング）。目の前の相手には当たらないが、遠い相手には早く届く。ジャンプ中に出すと、自分の少し前の門から斜め下へ飛ぶ（空中攻撃と合わせて1回のジャンプで1回）。画面に1つまで。
- **闇柱**（S＋O）：少し前の地面の門から、頭の上まで太い闇の柱が立つ対空技（自分の少し後ろから前へ130pxまで）。硬直は短め（22F、ガードされて−14）。柱は門から出るので、技を出している間に伸びるやられる範囲が小さい。

## 自動対戦と記録

（ver 0.6.0 からメニューには出ません。画面の部品は残してあります）CPU同士を画面を描かずに高速で何試合も戦わせて、結果を表で見られます（1000試合で10秒くらい）。バランス調整の参考にするためのものです。

1. 左右のキャラと強さ、試合数（100〜5000）、種（シード）をえらんで「開始」。
2. 「左右を入れ替えた試合も半分行う」にチェックすると、半分の試合は左右を入れ替えます（左右の有利不利を消すため）。
3. 途中で「中止」すると、そこまでの結果が出ます。「CSVで保存」でExcelなどで開けるファイルに保存できます。

同じ条件と種なら、何度やっても同じ結果になります。出る表：

- **全体**：試合数、平均試合時間（戦っている時間だけ）、時間切れの割合（ラウンドごと）など
- **キャラごとの勝率**：キャラ（強さ）ごとの勝ち・負け・引き分け、勝率、ラウンド勝率
- **技ごとの記録**：使った回数、当たった・ガードされた・投げ抜けされた回数、命中率（当たった÷使った）、与えたダメージとその割合

画面なしで動かすこともできます：`node tools/auto-battle.js kagetsu rin 1 1 1000 result.csv`（左のキャラ・右のキャラ・左の強さ・右の強さ・試合数・CSVの保存先。強さは0よわい・1ふつう・2つよい・3学習AI）。

## 学習AI（機械学習で強くなるCPU）

CPUの強さに「学習AI」があります。学習AIは、対戦をくり返して「この距離・この状況では何をすると勝てるか」を自分で覚えたCPUです（機械学習の一つ、強化学習の「Q学習」）。

- **覚えること**：様子見で次に何をするか（歩く・下がる・しゃがみガード・ステップ・3種類のジャンプ・各攻撃・必殺技・投げ・様子見の16種類から選ぶ）。
- **見ている状況**：相手との距離（6段階）、相手の様子（ふつう・しゃがみやガード・技を出している・技のスキ・のけぞりやガード硬直・空中）、自分と相手の飛び道具、画面端。全部で432通りの場面。
- **ほめられ方**：行動してから次に考えるまでに「相手に与えたダメージ − 受けたダメージ」が得点。ラウンドに勝つと+1、負けると−1。得点が高くなる行動の数字（Q値）が大きくなり、数字の大きい行動を選ぶようになる。
- **反射神経は「つよい」と同じ**：ガード・対空・連続技・投げ抜けの確率と反応の速さは「つよい」のまま。賢くなるのは立ち回りだけ。
- キャラの組み合わせごとに別の表を持つ（カゲツ対リン、リン対カゲツ、ゲンマ対カゲツなど、同キャラ同士も）。

はじめから学習済みのデータ（`src/core/learned-data.js`）が入っていて、どの組み合わせでも「つよい」CPUにほとんど勝ちます。

### キャラごとの方針（学習の手がかり）

学習AIは、キャラごとの「強い戦い方」を手がかりにして学びます（`src/core/learn.js` の `POLICY`）。わざと別の行動を試すとき、6割はこの方針の行動から選び、まだ何も覚えていない組み合わせは方針の行動を少しだけ高く見積もってから学び始めます。手がかりなので、試して損だった動きは学習で選ばれなくなります。

| キャラ | 方針 |
| --- | --- |
| カゲツ | 基本は待ち。大振り斬り（I）→ 飛刃（O）のキャンセルは隙が少ないので振りやすい（CPUはガードされても出す）。ジャンプ強攻撃で攻める。月影斬は切り返しと、相手が動いたのを見て |
| リン | ためた突進拳も使いながら近づき、回し蹴り（I・中段）と下段で崩す。練気は攻めている最中に出し、I・S＋U・S＋I → O をくり返して攻め続ける |
| ゲンマ | ジャンプと浮遊で逃げ回りながら異空間弾をまく（キャンセルの O は隙が大きいので使わない）。近づかれたら前後のワープで逃げる。冥府球をガードさせたら上りの空中攻撃と下段 |
| ゴウ | 張り手（U）で牽制し、四股踏み（S＋I）へキャンセル。大張り手（I）で近づいて岩落とし（O）。ダウンさせたら起き攻め（岩落とし・つかみ上げ・張り手の択）。大地落としはカゲツの月影斬と同じ使い方 |

この方針で4人を学び直した結果（16組み合わせ×4000試合×4回）。学習AI同士の勝率（最後の6世代の総当たりの平均、左のキャラの勝率）：カゲツ対リン 84%、カゲツ対ゲンマ 56%、カゲツ対ゴウ 43%、リン対ゲンマ 63%、リン対ゴウ 4%、ゲンマ対ゴウ 69%。「つよい」CPUにはほとんどの組み合わせで75〜100%勝ちますが、リンは カゲツに20%、ゴウに0% です。

学習AIの反射神経（反応10F・ガード85%・対空80%・連続技95%・投げ抜け60%）は「つよい」と同じです。ガードしないと決めた技の間は後ろを押さないので、「下がる」「しゃがみガード」を選んでいても、決めた確率より多くはガードできません。

### あなたとの対戦から学ぶ

プレイヤー VS CPU で強さを「学習AI」にすると、「あなたから学ぶ」を「する／しない」で選べます（はじめは「する」）。

- 「する」にすると、あなた専用の学習AI（はじめは今の学習AIのコピー）と戦います。試合をしながら表を直すので、あなたがよく使う攻め方に、だんだん対応してきます。
- あなたとの試合は数が少ないので、表を直す強さを大きめ（0.2）にして、数試合で変化がわかるようにしています。わざと別の行動を試す確率は5%です。
- あなた専用の学習AIは、試合が終わるたびに（途中でやめたときも、終わったラウンドまでを）このブラウザに保存されます。元の学習AIは変わりません。試合中は相手の名前の下に「あなたから学習中・何試合目」と出ます。
- 「学習AIをきたえる」画面の「あなたとの対戦で学んだ分を消す」で、今の学習AIからやり直せます。
- 例：近づいて投げばかりする相手に対して、学ばない学習AIは1試合に約2000ダメージ受けて負け続けますが、あなたから学ぶ学習AIは最初の10試合で平均255、21〜30試合目では平均52まで減りました。

### 学習AIをきたえる画面

（ver 0.6.0 からメニューには出ません。学び直しは `node tools/train.js` で）ブラウザの中でさらに学習させられます。

1. 学習するキャラ、相手のキャラ、練習相手（CPU よわい・ふつう・つよい、または学習AI。学習AIのときは「少し前の自分のコピー」が相手になり、500試合ごとに新しくなる）、試合数をえらんで「学習スタート」。
2. 学習中の勝率が50試合ごとにグラフで出ます。「実力をはかる」で、学習しないで「つよい」CPUと200試合戦った勝率を見られます。
3. 学習した結果はこのブラウザに保存され、ほかのモードで「学習AI」を選ぶと使われます。「ファイルに保存」「ファイルから読み込む」で持ち運べます。「何も覚えていない状態にする」で一から育てるところも見られます（「最初の学習データにもどす」でいつでも元にもどせます）。
4. 「学習AIの考え」の表で、よくある場面でどの行動を選ぶようになったかが見られます。

画面なしで学習させることもできます：`node tools/train.js 4000 4`（1回あたりの組み合わせごとの試合数と、回数。`--fresh` で一から学び直し）。相手は半分が「つよい」CPU、半分が「その回の始めの学習AIのコピー」です。両方を同時に学ばせると、先に勝ち始めた方に引っぱられて、もう片方が守りに閉じこもる（実力より弱くなる）ことがあったため、相手は学習しないコピーにしています。結果は `src/core/learned-data.js` に保存され、最後に「つよい」との勝率と、学習AI同士の勝率が出ます。相手には、つよいCPUのほかに、直前の回だけでなく最近6回分の始めのコピーからでたらめに選んだものも使います（直前のコピーだけだと、その弱点をつく戦い方を覚えては次の回に対応され…をくり返し、学習AI同士の勝率が回ごとに0%〜100%と大きく振れたため）。

バランス調整では `node tools/train.js 1000 6 --matrix` を使います。最近6世代どうしを、ちがうキャラの組み合わせ（カゲツ対リン・カゲツ対ゲンマ・リン対ゲンマ）ごとに総当たり（36通り×50試合）で戦わせて、平均の勝率を出します。1つの世代どうしの勝率はまだ大きく振れるので、この平均で見ます（同じ数値でも2回測ると39%と53%のように差が出るので、10ポイントより小さい差は見分けられません）。`--watch` をつけると回ごとの勝率も出ます。

## CPUのしくみ

CPUはプレイヤーと同じキー入力を作るだけで、特別な動きはしません。強さは `src/core/cpu.js` の `LEVELS` の数字で決まります。

| 項目 | よわい | ふつう | つよい |
| --- | --- | --- | --- |
| 反応の速さ（相手の位置やジャンプが何F遅れて見えるか、様子見の考え直しの間隔） | 30F | 18F | 10F |
| ガードできる確率（相手の技1つごと。下段・空中攻撃も正しい向きで） | 30% | 60% | 85% |
| 対空技を出す確率（相手のジャンプ1回ごと） | 20% | 50% | 80% |
| 連続技を最後までつなぐ確率（失敗すると途中で止める） | 30% | 70% | 95% |
| 投げ抜けする確率 | 0% | 30% | 60% |

- 離れているとき：カゲツは飛刃を撃つか歩いて近づく。リンは歩く・ダッシュ・ジャンプで近づく。ゲンマは異空間弾を撃つか、垂直ジャンプで浮いて空中から異空間弾を撃つ。近づかれると後ろへワープで離れる。
- 中くらいの距離（強攻撃が届く）：大振り斬り・回し蹴りで牽制、足払いも混ぜる。
- 近いとき（弱攻撃が届く）：弱攻撃から連続技、下段、投げで揺さぶる。
- 相手がジャンプしたら対空技（S＋O）、相手が技を出したら上段・下段を見てガード。
- ガードは発生の速い技を見てからでは間に合わないので、「ガードできる確率」で読んで構える形にしています。
